# MarbleBox
A boxing shaped marble run for up to four people

![MarbleBox-Boceto](MarbleBox-Boceto)

So, this project is based on a boxing ring as the description mentions, its a very squared design wich is the style I usually go for in my designs, it features two twin chutes, with a couple of ramps, a set of stairs and then a drop that lands into another ramp straight into a little hole in the middle that is going to be covered by a circular sheet of clear acrylic, here are some images of the finished model plus some along the way
